# 16 — Changelog e versionamento

Este projeto segue **SemVer** (`MAJOR.MINOR.PATCH`).

## Regras de bump automático

- **MAJOR**: `BREAKING CHANGE` ou `!:`
- **MINOR**: commit começando com `feat`
- **PATCH**: demais commits

Veja também: `docs/RELEASING.md`.

## Changelog

As releases são criadas no GitHub com release notes automáticas.
